## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the `entry.png` rendered by `gen_image.py` into the output directory. Render the image again with `python3 gen_image.py` (Pillow only, no network).
